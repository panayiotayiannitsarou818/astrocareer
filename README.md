# AstroCheck Career

Αυτόνομη ιστοσελίδα, αποκλειστικά για την υπηρεσία ανάδειξης ταλέντων και
διερεύνησης επαγγελματικών επιλογών — ενιαία υπηρεσία για κάθε άτομο, χωρίς
διάκριση παιδιού/εφήβου/ενήλικα.
Δεν εξαρτάται από, ούτε συνδέεται με, καμία άλλη υπηρεσία.

**Entry point:** `app.py` (χρειάζεται επίσης τα `core/`, `references/` και `requirements.txt` δίπλα του για να τρέξει)
(Main file path στο Streamlit Community Cloud = `app.py`)

## Χαρακτηριστικά

- **v22: Μηχανή ταλέντων (προεπιλογή).** Ο πελάτης παίρνει αμέσως την αναφορά, χωρίς AI και
  χωρίς κόστος. Τα ταλέντα και οι τομείς προκύπτουν από κανόνες (`core/talent_engine.py`,
  πίνακες στο `core/talent_map.py`, Κανόνες 4–7, 10, 12, 15 της εντολής v13) και τα κείμενα από
  έτοιμη βιβλιοθήκη (`core/data/talent_texts.json`). Ο ίδιος χάρτης δίνει πάντα την ίδια αναφορά.
  Εσωτερικό δελτίο: όλοι οι δείκτες, η βάση τεκμηρίωσης, ο φραγμός υγείας, οι απορρίψεις.
  - `REPORT_MODE = "hybrid"`: φτηνό AI γράφει ΜΟΝΟ συνδετικές προτάσεις (εισαγωγή, σύνδεση ανά
    ταλέντο, πρόταση ανά τομέα) για τους κωδικούς που βρήκε η μηχανή· την αναφορά τη συνθέτει η εφαρμογή
    με σταθερά κείμενα βιβλιοθήκης (`core/talent_polish.py`). Αν δεν περάσει τον έλεγχο ανά πεδίο, ο
    πελάτης παίρνει την εκδοχή Α. Ο έλεγχος είναι μηχανικός· η Διαχείριση κατεβάζει Α και Β για σύγκριση.
  - `REPORT_MODE = "ai"`: η παλιά πλήρως αυτόματη ροή με AI (περιγράφεται παρακάτω).
  - Οι πίνακες και τα κείμενα είναι **πρόχειρα μέχρι να τα εγκρίνει αστρολόγος**. Με
    `REQUIRE_APPROVAL = "1"` (προεπιλογή) οι πελάτες δεν παίρνουν πλήρη αναφορά πριν από την έγκριση.
    Η έγκριση ελέγχει τη συνέπεια της αστρολογικής μεθόδου· δεν αποτελεί επιστημονική επικύρωση ικανοτήτων.
- **v21: Δωρεάν ταλέντο** από έτοιμη βιβλιοθήκη (`core/teaser.py`), χωρίς AI.

- **v20: Υπολογισμός χάρτη μέσα στην εφαρμογή.** Ο πελάτης δίνει ημερομηνία, ώρα,
  χώρα και τόπο γέννησης — χωρίς PDF του Astrodienst. Ίδια αποτελέσματα με το
  Astrodienst στα 6 παραδείγματα (θέσεις ±1″, Οίκοι, όψεις). Λεπτομέρειες:
  `CHANGELOG_v20_ypologismos_xarti.md`. Άδειες: Skyfield/skyfield-data (MIT),
  NASA/JPL DE421 (δημόσιο αγαθό), GeoNames (CC-BY 4.0) — χωρίς Swiss Ephemeris/AGPL.

- Ανάγνωση Astrodienst Natal Chart Data Sheet (PDF) — δεν χρειάζεται καμία
  πλήρης ανάλυση 12 Οίκων.
- **Selectbox γλώσσας πάνω-δεξιά (Ελληνικά/English)** που αλλάζει ολόκληρη
  τη σελίδα ΚΑΙ τη γλώσσα του τελικού παραδοτέου. Προεπιλογή: Ελληνικά.
- Ενιαία, "Απλή και πρακτική" παρουσίαση για όλους — όσα ταλέντα και
  επαγγελματικοί τομείς τεκμηριώνονται πραγματικά από τον χάρτη, χωρίς
  σταθερό ελάχιστο ή ανώτατο αριθμό και χωρίς επιλογή τύπου υπηρεσίας.
- **Σελίδα πελάτη (v17.1):** ο πελάτης ανεβάζει τον χάρτη του, πατά ένα
  κουμπί και κατεβάζει την εγκεκριμένη αναφορά. Δεν βλέπει τίποτε άλλο.
  Αν μια αναφορά δεν εγκριθεί ποτέ (σπάνιο), ο πελάτης ΔΕΝ παίρνει πρόχειρο —
  βλέπει μόνο ευγενικό μήνυμα να ξαναδοκιμάσει.
- **Διαχείριση (μόνο εσύ):** «🔒 Διαχείριση» στο πλάι με τον κωδικό
  `ADMIN_PASSWORD` — λεπτομέρειες προόδου, τεχνικό δελτίο, πρόχειρα,
  επιλογή μοντέλου, χειροκίνητη διαδικασία.
- **Λειτουργία "ai" (μέχρι το v21 ήταν η βασική): ανεβάζεις μόνο το PDF και πατάς ένα κουμπί.**
  Ανάγνωση PDF → δημιουργία με Claude (ή OpenAI) → μηχανικός έλεγχος →
  αυτόματη διόρθωση ξανά και ξανά μέχρι την έγκριση → τελικό Word πελάτη +
  εσωτερικό τεχνικό δελτίο. Το τελικό έντυπο δίνεται για λήψη ΜΟΝΟ αν
  εγκριθεί· αλλιώς δίνεται ως «ΠΡΟΧΕΙΡΟ» με τη λίστα προβλημάτων.
- Η παλιά χειροκίνητη διαδικασία (εντολή για ChatGPT/Claude → ανέβασμα →
  έλεγχος) παραμένει ως εφεδρική, κλειστή στο κάτω μέρος της σελίδας.
- **v18:** κύκλος διόρθωσης με πρόωρες διακοπές, προαιρετικός γύρος ποιότητας,
  μετρητής/όριο κόστους (μόνο Διαχείριση), βήματα 1–4 με εκτίμηση χρόνου,
  «▶️ Συνέχεια» μετά από διακοπή. Όλες οι ρυθμίσεις: `.streamlit/secrets.toml.example`.
- Μαζική εκτέλεση χωρίς διεπαφή: `batch_run.py` (φάκελος με PDF → φάκελος με Word).
- **v19 — έλεγχος πληρότητας:** το λογισμικό υπολογίζει τις συγκεντρώσεις
  πλανητών (3+ στο ίδιο ζώδιο ή Οίκο) και το τεχνικό δελτίο πρέπει να έχει
  ρητή απόφαση για κάθε σημείο, κάθε συγκέντρωση και κάθε τομέα του καταλόγου
  («Παράρτημα Κάλυψης Θέσεων», «Παράρτημα Κάλυψης Τομέων»). Δες
  `CHANGELOG_v19_kalypsi.md`.
- Πλήρης μηχανικός έλεγχος πληρότητας (`core/validator.py`) πριν επιτραπεί η
  λήψη του τελικού Word — για την απλή παρουσίαση, ελέγχει ξεχωριστά το
  καθαρό παραδοτέο πελάτη ΚΑΙ το εσωτερικό τεχνικό δελτίο.

## Deployment (Streamlit Community Cloud)

1. Ανέβασε όλο τον φάκελο σε ένα GitHub repo.
2. Deploy στο https://share.streamlit.io με **Main file path = `app.py`**.

3. Στο App → Settings → **Secrets** βάλε τις ρυθμίσεις (όλες εξηγούνται στο
   `.streamlit/secrets.toml.example`):

   ```toml
   ADMIN_PASSWORD = "δικός-σου-κωδικός"
   REPORT_MODE = "engine"           # ή "hybrid" / "ai"
   ANTHROPIC_API_KEY = "sk-ant-..." # μόνο για "hybrid" / "ai"
   ```

   Με `REPORT_MODE = "engine"` δεν χρειάζεται κλειδί API. Με "ai" και χωρίς κλειδί, ο πελάτης
   βλέπει «η υπηρεσία δεν είναι διαθέσιμη».
   Προαιρετικά: `OPENAI_API_KEY`, `AI_PROVIDER`, `ANTHROPIC_MODEL`,
   `OPENAI_MODEL`, `AUTO_MAX_ATTEMPTS`, `AUTO_FRESH_ROUNDS`.

## Μαζική εκτέλεση (χωρίς ιστοσελίδα)

```bash
export ANTHROPIC_API_KEY=sk-ant-...
python batch_run.py pelates/            # όλα τα PDF του φακέλου
python batch_run.py maria.pdf --lang en
```

Τα αποτελέσματα γράφονται στον φάκελο `apotelesmata/`.

## Τοπική εκτέλεση

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/streamlit run app.py
```

## Ο κοινός πυρήνας (`core/`)

Ο κώδικας που κάνει την πραγματική δουλειά — `models.py`, `astrology.py`,
`parser.py`, `validator.py`, `prompts.py`, `docx_builder.py`, `generator.py`,
`reference_loader.py`, `case_state.py`, `pipeline.py` (η ροή "ai"), `costs.py` (κόστος), `eta.py` (εκτίμηση χρόνου),
`ephemeris.py`/`chiron.py`/`places.py`/`birthtime.py` (υπολογισμός χάρτη), `teaser.py` (δωρεάν ταλέντο),
`talent_map.py`/`talent_engine.py`/`talent_texts.py`/`talent_report.py`/`talent_polish.py` (μηχανή ταλέντων) — ζει στο `core/` ως πραγματικό
Python πακέτο. Το κοινό .docx πρότυπο και η δεσμευτική εντολή ζουν στο
`references/`.

## Development / Tests

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/pip install -r requirements-dev.txt

```

Το `tests/fixtures/astro_paradeigma.pdf` (το δημόσιο παράδειγμα "Paradeigma"
του Astrodienst) είναι ήδη μέσα στο repo — τα tests τρέχουν χωρίς καμία
επιπλέον ρύθμιση.

## Σημαντικό

Η εφαρμογή δεν αντιμετωπίζει την αστρολογία ως επιστημονική ή ψυχολογική
διάγνωση — είναι εργαλείο συμβολικής αυτογνωσίας. Η τελική ανάλυση πρέπει να
περνά ανθρώπινο μαθηματικό, γλωσσικό και οπτικό έλεγχο πριν παραδοθεί σε
πελάτη. Το ChatGPT ή το Claude πραγματοποιούν μόνο αυτοέλεγχο· ο πραγματικός
validator εκτελείται αποκλειστικά μέσα στο AstroCheck Career.
